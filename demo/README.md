# GridGuard AI Demo Evidence

This directory contains demo artifacts, video links, live deployment URLs, and screenshots for the **IBM Bob Hackathon** submission.

## Files

- `demo-video-link.txt`: Link to the 3-minute video demonstration.
- `live-demo-url.txt`: URL to the live hosted application instance.
- `screenshots/`: High-resolution UI screenshots demonstrating operational workflows.

## Key Demo Workflows

1. **Grid Control Overview & KPI Summary**: Real-time overview of grid reliability score, critical assets, active incidents, and crew readiness.
2. **Multi-Factor Risk Analysis & Ranking**: Risk decomposition matrix and formula attribution breakdown.
3. **Asset Lifecycle CRUD Operations**: Registering new assets (e.g. `T-406`) and observing instant propagation to PostgreSQL and all UI modules.
4. **Load-Bearing IBM Bob Assistant**: Conversational diagnostic deep-dive into Transformer `T-104` and direct execution of work orders and crew dispatches via chat action buttons.
